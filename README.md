<h2>▶️ How to Run</h2>

<p>Follow these steps to run any Java program from this repository:</p>

<h3>1️⃣ Install Java JDK</h3>

<p>
Make sure the <b>Java Development Kit (JDK)</b> is installed and configured on your system.
</p>

<h3>2️⃣ Clone the Repository</h3>

<pre>
git clone https://github.com/tusharkantapalo/java_learning_journey.git
</pre>

<h3>3️⃣ Navigate to the Repository</h3>

<pre>
cd java-lab-programs
</pre>

<h3>4️⃣ Navigate to the Required Lab</h3>

<pre>
cd Lab-01
</pre>

<h3>5️⃣ Compile the Program</h3>

<pre>
javac Program1.java
</pre>

<h3>6️⃣ Run the Program</h3>

<pre>
java Program1
</pre>
